# Smart Expense Tracker Application

**Author:** Mahendra Patel

**Project:** Python - Data Analysis

## Introduction

The Smart Expense Tracker is a simple Python-based project that helps users record and manage their daily expenses. It also helps users understand their spending habits by calculating total expenses, average expenses, and category-wise spending.

This project is made using Python and different data analysis libraries.

## Objectives

- To record daily expenses.
- To calculate total and average expenses.
- To filter expenses by category, date, and amount.
- To generate a simple expense report.
- To display expenses using different graphs.
- To understand the use of Python, NumPy, Pandas, Matplotlib, and Seaborn.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Features

1. **Add Expense:** Users can enter the date, amount, category, and description of an expense.
2. **View Summary:** Displays total expenses, average expenses, and category-wise spending.
3. **Filter Expenses:** Allows users to search expenses by category, date range, or minimum amount.
4. **Generate Report:** Displays important information such as the highest expense, lowest expense, and highest spending category.
5. **Data Visualization:** Shows bar charts, line graphs, pie charts, and histograms.
6. **CSV File:** Stores expense data in a CSV file for future use.

## Project Files

The project contains the following files:

- `expense_tracker.py` – Main Python program.
- `expenses.csv` – Dataset containing expense details.
- `README.md` – Project description and instructions.

The `expenses.csv` file is created automatically by the program if it does not already exist.

## Installation

First, make sure Python is installed on your computer.

Install the required libraries by running the following command:

```bash
pip install pandas numpy matplotlib seaborn
```

## How to Run the Project

1. Download or copy the project files into a folder.
2. Open the folder in VS Code or a terminal.
3. Run the following command:

```bash
python expense_tracker.py
```

4. Select an option from the menu.
5. Enter the required details to manage and analyze expenses.

## Dataset Details

The dataset contains the following columns:

- **Date:** Date of the expense.
- **Amount:** Amount spent.
- **Category:** Type of expense, such as Food, Transport, Utilities, or Entertainment.
- **Description:** Short details about the expense.

Example:

| Date | Amount | Category | Description |
|---|---:|---|---|
| 2026-01-01 | 200 | Food | Lunch |
| 2026-01-05 | 500 | Transport | Bus |
| 2026-01-10 | 150 | Food | Dinner |

## Data Visualization

The project provides four types of graphs:

- **Bar Chart:** Shows total expenses for each category.
- **Line Graph:** Shows monthly spending trends.
- **Pie Chart:** Shows the percentage of spending in each category.
- **Histogram:** Shows the frequency distribution of expense amounts.
